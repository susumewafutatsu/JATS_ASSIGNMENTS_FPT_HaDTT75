# DevDash - Typed Async Dashboard

## Mô tả
Dashboard quản lý sản phẩm sử dụng TypeScript (strict mode) và Fetch API.

## Các tính năng đã hoàn thành
- [x] **Pass Tier**: Fetch dữ liệu theo chuẩn Interface, xử lý Error state, Detail view.
- [x] **Good Tier**: Dùng Generic `fetchJson<T>`, Promise.all, HOF (map/filter).
- [x] **Excellent Tier**: Discriminated Union cho state, Debounce closure, Module architecture.

## Hướng dẫn chạy
1. `npm install`
2. `npm run dev`
